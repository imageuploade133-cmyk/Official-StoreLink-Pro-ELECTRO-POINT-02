# StoreLink Pro - E-commerce & POS Platform

StoreLink Pro is a comprehensive, multi-tenant solution for modern retailers, combining a powerful Point of Sale (POS) system with a fully-integrated E-commerce storefront.

## Features

- **Multi-tenancy**: Support for multiple stores with data isolation.
- **POS System**: Real-time inventory management, barcode scanning, and payment processing.
- **E-commerce Storefront**: Customizable online stores for every merchant.
- **AI-Powered**: Background removal for product images and more.
- **Multi-payment Support**: Integrated with Stripe, PayPal, Paystack, and Adyen.

## Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend**: Firebase (Firestore, Auth, Storage)
- **AI**: Google Genkit
- **Payments**: Stripe, PayPal, Paystack, Adyen

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables in `.env`
4. Run the development server: `npm run dev`
